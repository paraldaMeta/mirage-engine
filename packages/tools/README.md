# @mirage/tools

Quality and packaging tools; they drive the local Chrome (`/Applications/Google Chrome.app`, or `$CHROME`) headless
with the GPU on through puppeteer-core. Targets are a built `dist/` folder (served on 127.0.0.1) or a packaged
`.html` (opened from file://).

| tool | |
|---|---|
| `src/gpu-ci.mjs run` / `collect` | GPU runner adapter for serial acceptance, hardware preflight, partial evidence and Actions artifacts. [Runner setup](../../docs/GPU-CI.md). |
| `src/typecheck.mjs --out <new-dir>` (`npm run test:types -- ...`) | Test machine only: pack core/world/play/game, install the tarballs and a pinned compiler in a separate consumer, compare the Rapier declarations, then compile TypeScript and checked JavaScript with NodeNext and Bundler. Keeps package contents, hashes, lock and logs; no rendering. [Type handoff](../../docs/TYPES.md). |
| `src/acceptance.mjs --run --machine <json> --out <new-dir>` (`npm run acceptance -- ...` at the root) | Test-machine-only serial acceptance of a clean HEAD archive: install, CPU checks, every example, physics, touch, stillness, GPU load, five still views, kit metrics and character review. Keeps logs, screenshots, source hashes and a pending human review; never certifies 1.0. See [the handoff](../../docs/ACCEPTANCE.md). |
| `mirage-validate-plan <file> [--json]` | Validate a local JS module's default export or a JSON plan with the same rules used by the loader. Prints all invalid field paths, then the same problems as [diagnostics](../../docs/diagnostics.md) (`--json`: only those, as a JSON array). Exits 0 for a valid plan, 1 for an invalid or unreadable file and 2 for incorrect usage. |
| `mirage-check <dist \| page.html \| url> [--json]` (`src/check-world.mjs`) | the world check: load once, list every [diagnostic](../../docs/diagnostics.md) that needs no scenario (plan, failed modules, spawn and viewpoints inside solids, floating objects, coplanar surfaces, what each viewpoint shows, triangle budget, black frame, console errors); exit 1 on any error |
| `src/vite-rapier.mjs` (`rapierWasm()`) | Vite plugin for pages that use @mirage/game: Rapier's wasm as its own file (fetched and compiled while it downloads) instead of base64 in the bundle; 814 → 594 KB gzip on garden-quest. Single-file pages keep it inline |
| `src/package.mjs <example> [--out f.html]` | one standalone HTML file: Vite build, every asset inlined, no code splitting, workers as Blob URLs started classic (file:// cannot start module workers from Blobs) |
| `src/playtest.mjs <scenario.json> <target> [--out dir] [--baseline dir] [--phone]` | the agent self-test loop: a JSON scenario of placements, held keys, taps, `walkTo` routes, `lookAt` (points or game entities), `flicker` along a path, `perf` (frame cost), `see` (what share of the final view named objects cover, from an ID pass, with the reason when too little: out of frame, hidden by what, too small); expectations on position, collision, game state (`near prompt inventory flags.*`), flicker, frame time, screenshot exposure (`luma dark clipped`), console errors; every problem also as a coded [diagnostic](../../docs/diagnostics.md) with a concrete fix (`report.json` `diagnostics`, the top of `report.md`), plus load-time world checks; writes `report.md`, `report.json`, one screenshot per step, `sheet.png` (contact sheet) and the worst flicker triple (`-worst.png`, `-worst-diff.png`); each `walkTo` writes `NN-<step>-route.png` after the walk (the walk grid from above: planned route, path taken, stuck point; `"onion": true` adds the game entities that moved); a step's `"contrast": true` audits the WCAG contrast of every visible prompt / HUD line against the pixels behind its glyphs (MG710); a scenario `"baseline": "dir"` compares each fixed view (place / viewpoint) on the deterministic still path with `dir/<shot>` by region SSIM (MG460); `"phone": true` shoots 375 × 812; a field the runner does not know is listed (`report.unknownFields`); exit 1 on any failure |
| `src/walktest.mjs` | M2's walk tests: an alias of playtest (same scenario format) |
| `src/gpu-load.mjs <dist...> [--idle s]` | GPU load per built example: frames drawn when still (after the idle time, 10 s), with the tab hidden (0 frames, 0 callbacks, audio suspended), while walking (at most the display rate and 60) and in power saver (at most 30); exit 1 on any failure |
| `src/touch-check.mjs <dist...> [--frames 40]` (`npm run test:touch`) | a phone-sized page with touch emulation and real touch events: plain play walks, runs and looks by finger (from an orbit view through the touch bar's Walk button); a game starts on a tap and its stick walks and, pushed past the rim, runs; exit 1 on any failure |
| `src/snap.mjs <target> [--out dir] [--views all] [--spp 16] [--game] [--alpha]` | every plan viewpoint as a still (the core's still path), plus `sheet.png` (a contact sheet) and `snap.json`; `--alpha`: PNGs with a transparent sky (core's `world.renderTransparent`: rendered over black and over white, straight alpha recovered; written exactly by `src/png.mjs`) |
| `looks.check.mjs [--scene metals \| alpha \| fur] [--out out/looks]` | browser check of the opt-in looks, no build (serves `check/looks.html` from the repository root): the metal PROCs, the transparent still (background alpha 0, partial alpha only at edges, colours as the still over black), shell fur (one draw per patch, moss on a mesh), reduced motion (less sway, back to identical when off, play following `prefers-reduced-motion`); saves the stills |
| `src/snap.mjs <target> [--out dir] [--views all] [--spp 16] [--game] [--phone] [--baseline dir] [--ssim 0.92,0.85,0.75] [--determinism] [--variants "a=1;b=2"] [--adaptive [levels]] [--adaptive-check]` | every plan viewpoint as a still (the core's still path), plus `sheet.png` (a contact sheet) and `snap.json`. `--baseline`: region SSIM against `dir/<file>` (8 × 8 windows, 4 × 4 cells; mean / 5th percentile / worst cell), grain 0; a miss is MG460 with `baseline-diff-*.png` (baseline \| now, worst cell boxed); missing files are written. `--determinism`: each view again after another view and after a reload, bit-identical or MG461. `--variants`: one labelled grid per view (`variants-*.png`, ≤ 16, 4 columns); `time=` (golden, dawn, noon, dusk, night, HH:MM, elevation,azimuth) and dotted world settings (`post.bloom=0.2`) change in place, other keys reload with that query. `--phone`: 375 × 812, sheet one phone wide per tile. `--adaptive`: renderFrame's `converge` (stops once the still settles). Exit 1 when a check fails |
| `determinism.check.mjs [dist...]` (`npm run test:determinism`) | `snap --determinism` over every example's `dist/` (all seven, after `npm run build:examples`) |
| `src/export.mjs <target> [--out world.glb] [--usdz world.usdz] [--bake 1024] [--density 64] [--maps color,orm,normal] [--png] [--usdz-thin 1] [--verify dir] [--views all] [--no-validate]` (`mirage-export`) | the built world as GLB (Blender, Android Scene Viewer, any glTF viewer) and USDZ (Quick Look): patch() surfaces baked into atlas textures (base colour, roughness/metalness, normal), instancing kept in the GLB (`EXT_mesh_gpu_instancing`); sky, stars, collision proxies and the figure left out. Writes `<out>.export.json`; `--verify` renders the re-imported GLB (and USDZ) next to the live world from every viewpoint (`vNN-<name>.png`: live, export, difference) with coverage, normal and colour numbers; gltf-validator (a devDependency) runs unless `--no-validate`. Routes and numbers: [docs/export.md](../../docs/export.md). Page side: `exportWorld(world, opts)` in `@mirage/core/export`. |
| `src/perf.mjs <target> [--w 1440 --h 900]` (`mirage-perf`) | synchronous frame cost: walk, game view, fly (moving, TAA) and the still path at spp 6 / 16; draw calls, triangles |
| `src/e2e.mjs [--only a,b] [--no-file]` (`npm run test:e2e` at the root) | every example with a `playtest` script, in sequence: build, playtest of `dist/`, the example's extra scripts (garden-quest's playthrough), package, playtest of the single file from file://; keeps going after a failure, prints a summary, writes `out/e2e/summary.json`; exit 1 if any step failed |
| `src/deploy.mjs <example> [--out dir] [--multi]` | a folder any static host can serve (single file or Vite's dist, `.nojekyll`, `_headers`); checks it, prints how to publish. **Uploads nothing.** |
| `tex/pack.py` | fetch CC0 texture sets from Poly Haven and pack them (M1b) |

Scenario step: `{ name, place: { eye, look, mode }, viewpoint, mode, walkTo: [[x, z]], lookAt, tap: 'Space', keys: ['KeyW'], ms,
flicker: { path }, perf: { frames }, expect: { z: '> 8.6', y: '~ 1.6 0.05', 'flags.lit': '== true', flicker: '< 8' }, see, contrast, shot, baseline }`;
the vocabulary is `src/scenario-fields.mjs` (`agent/check.mjs` fails a skill that names anything else); full
reference in the header of `src/playtest.mjs`; how agents use it: `agent/mirage-playtest/SKILL.md`. Scenarios:
`examples/*/scenarios/*.json`.

Chrome (`src/chrome.mjs`): puppeteer's defaults already carry the capture flags (`--force-color-profile=srgb`,
`--disable-renderer-backgrounding`, `--disable-background-timer-throttling`, `--disable-backgrounding-occluded-windows`);
`launch()` adds `--disable-background-media-suspend`, no component updates or pings, and no intensive wake-up
throttling (`CAPTURE_ARGS`; stills before / after bit-identical). `lease()` hands out one Chrome per command line for a
whole tool run (each lease gets its own browser context: no localStorage, saves or HTTP cache shared between leases;
closed with its pages on release; a crashed Chrome leaves the pool; the browser closes 1.5 s after the last release,
or at `drain()`); `MIRAGE_POOL=1` makes every `launch()` lease. A loop that opens a page per item saves the launch:
~0.3 s per page (woodland-path: open + ready + one still, median 611 → 317 ms, 6 interleaved pairs).
