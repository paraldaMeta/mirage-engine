# 交给 Cursor 的测试和修改清单

**第一轮（查 bug 和测试）的现成指令在 [CURSOR-ROUND1.md](CURSOR-ROUND1.md)。**

主线（M3 → M4/M5）由 Claude 继续做。下面这些是**可以并行交给 Cursor** 的活：测试、补洞、打磨。每条都写了要读什么、怎么算完成。

## 共同规则（每条任务都适用）

1. 先读 `PLAN.md` 第 2 节（许可）、`docs/world-protocol.md`、对应包的 README 和 `docs/M*-notes.md` 里的「open problems」。
2. **不复制 Golden Temple 的代码**（它的技术思路可以参考，代码要自己写）。引擎仓库里**不放任何具体城市、地方材质或作者原作品的内容**。
3. 代码尽量少（ponytail 原则）：能用 three.js 自带的就不自己写，不加用不上的抽象；故意简化的地方写 `// ponytail:` 注释，说明上限和以后怎么升级。
4. 改完必须跑：`npm test`（所有包），以及受影响示例的走动测试 / 通关脚本（`packages/tools`）。截图对比要用真 Chrome。
5. 静止帧像素一致是硬指标：同一机位、同一帧号，两次渲染差值必须是 0。
6. 每个任务一个分支、一个提交；提交信息写清楚改了什么、测了什么、数字是多少。**不要推到 main，不要改仓库可见性**。
7. 新素材只收 CC0 或自制，并在 `CREDITS.md` 加一行。
